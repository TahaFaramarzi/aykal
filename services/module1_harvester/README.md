# 📊 iCall Project — Phase 1

> **ماژول سرنخ‌یابی هوشمند اینستاگرام** بر پایه API رسمی Meta + Groq LLM

## 🎯 خلاصه اجرایی

پروژه **iCall** با هدف ساخت یک **دستیار هوشمند پاسخ‌گویی** برای پیج‌های اینستاگرام تجاری طراحی شده است. در **فاز ۱**، زیرساخت اصلی شامل دریافت Webhook، تحلیل هوشمند نیت کاربران با LLM، و خوشه‌بندی خودکار سرنخ‌های فروش پیاده‌سازی شده است.

**نکته کلیدی:** این پروژه **منحصراً** از API رسمی Meta استفاده می‌کند و به هیچ‌وجه از روش‌های غیرمجاز مثل خزش (Scraping) یا شبیه‌سازی رفتار کاربر (Selenium) بهره نمی‌برد. این تصمیم، مطابق با سیاست‌های Meta Platform و سند فنی پروژه iCall است.

**دستاورد اصلی فاز ۱:** تبدیل تعاملات خام (کامنت، دایرکت) به **سرنخ‌های فروش قابل‌اقدام** با امتیاز، وضعیت، و پاسخ پیشنهادی AI.

**جریان داده گام‌به‌گام:**

۱. **کاربر** روی پیج تو کامنت می‌ذاره یا دایرکت می‌فرسته

۲. **Meta** یه Webhook POST به سرور تو می‌فرسته (با امضای HMAC)

۳. **FastAPI** امضا رو تأیید می‌کنه، payload رو parse می‌کنه و **سریع 200 OK** برمی‌گردونه

۴. تسک به **Celery** صف می‌شه (پردازش سنگین در پس‌زمینه)

۵. **Intent Classifier** با **Groq LLM** نیت کاربر رو تشخیص می‌ده

۶. **Reply Generator** با LLM یه پاسخ فارسی مناسب تولید می‌کنه

۷. **Lead Harvester** تعامل رو ثبت می‌کنه، امتیاز رو آپدیت می‌کنه و وضعیت کاربر رو تعیین می‌کنه

۸. داده در **PostgreSQL** ذخیره می‌شه

۹. از طریق **REST API** یا **Streamlit Dashboard** قابل مشاهده‌ست

## 🧩 ماژول‌های اصلی

### 🎯 Lead Harvester (`app/services/lead_harvester.py`)

قلب فاز ۱ — تعاملات رو ثبت می‌کنه، امتیاز می‌ده و کاربر رو خوشه‌بندی می‌کنه.

**آستانه‌های امتیاز:**

| امتیاز | وضعیت | معنی |
|--------|--------|------|
| 0-5 | `active` | کاربر جدید |
| 5-10 | `engaged` | درگیر شده |
| 10-15 | `warm` | علاقه‌مند |
| **15+** | **`hot`** | **🔥 آماده خرید** |
| 30 روز غیرفعال | `cold` | سرد شده |
| 90 روز غیرفعال | `lost` | از دست رفته |

**توابع اصلی:**
- `process_interaction(db, data)` → پردازش کامل یه تعامل (نیت + پاسخ + ذخیره)
- `mark_inactive_leads(db)` → علامت‌گذاری کاربران غیرفعال
- `get_lead_clusters(db)` → آمار خوشه‌بندی

### 🧠 Intent Classifier (`app/services/intent_classifier.py`)

نیت کاربر رو از متن تشخیص می‌ده:
- **مرحله ۱:** با LLM (Groq + `openai/gpt-oss-120b`)
- **مرحله ۲ (Fallback):** با rule-based (اگه LLM در دسترس نباشه)

**نیت‌های پشتیبانی‌شده:**

| نیت | کلیدواژه‌ها | امتیاز |
|-----|-------------|--------|
| `purchase_inquiry` | قیمت، خرید، سفارش، موجود، تخفیف | ۹ |
| `human_handoff_request` | اپراتور، مدیر، کارشناس | ۸ |
| `support_complaint` | شکایت، خراب، دیر رسید، مرجوع | ۷ |
| `location_info` | آدرس، کجاست، ساعت کاری | ۵ |
| `general_comment` | سایر کامنت‌ها | ۳ |
| `general_engagement` | لایک تنها | ۲ |
| `spam` | فالوور رایگان، جایزه، کریپتو | ۰ |
| `unknown` | نامشخص | ۱ |

### 🤖 LLM Service (`app/services/llm_service.py`)

اتصال به **Groq** و دو قابلیت اصلی:

**۱. `classify_intent_with_llm(text, type)`**
- تشخیص نیت با AI
- Confidence Score (0.0 تا 1.0)
- خروجی JSON: `{"intent": ..., "confidence": ..., "reason": ...}`

**۲. `generate_reply(text, intent, context)`**
- تولید پاسخ فارسی هوشمند
- لحن دوستانه + کوتاه
- ایموجی مناسب

**نکته:** اگه LLM در دسترس نباشه، به rule-based fallback می‌کنه.
